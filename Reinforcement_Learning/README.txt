Reinforcement Learning - Q-Learning
Student: Janani Veerakumar
Dataset: Titanic

This implementation applies Q-Learning to a Titanic survival prediction environment.
State: passenger feature combination such as Pclass, Sex, AgeBand, FareBand and CabinKnown.
Actions: 0 = not survived, 1 = survived.
Reward: +1 for correct prediction, -1 for incorrect prediction.

Output files:
- qlearning_reward_graph.png
- qlearning_training_accuracy.png
- qlearning_confusion_matrix.png
- qlearning_metrics_bar.png
- classification_report.txt
- results_summary.csv
